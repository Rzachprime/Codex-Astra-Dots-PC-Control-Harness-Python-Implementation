# Python Windows Desktop Control Toolkit
This is a python toolkit for Dots to control windows pc's due to built in Codex tools not working with it.

This plan describes a small Python standard-library backend for authorized Windows UI tasks when an agent's official desktop tools are unavailable.

**IMPORTANT** sandbox_permissions="require_escalated" was required for Dots agent to successfully use this tool. I prompted it to run the toolkit as an administrator which in turn
caused it to create a custom rule for me to approve. This elevated permission allowed it to use the toolkit successfully.
